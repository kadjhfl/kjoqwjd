HAWRAZ v2.14 — تعمیر راه‌اندازی و کش آفلاین

هدف این نسخه جلوگیری از صفحه سفید ناشی از خطاهای JavaScript یا پاسخ اشتباه Service Worker است.

تغییرات:
- Service Worker جدید با cache v16.
- فایل HTML فقط برای درخواست navigation به عنوان fallback برگردانده می‌شود؛ هیچ‌گاه به جای app.js یا style.css پاسخ داده نمی‌شود.
- هنگام نصب cache، شکست بارگیری یک asset باعث شکست کل نصب Service Worker نمی‌شود.
- خطاهای uncaught JavaScript و Promise به صورت پیام قابل مشاهده نمایش داده می‌شوند.
- URL فایل‌های CSS و JS در صفحه نسخه‌دار شده‌اند.
- پایگاه داده IndexedDB حذف یا تغییر ساختار داده نشده است.

تست‌های پیشنهادی پس از نصب:
1. بازکردن برنامه در پنجره عادی و بررسی صفحه قفل.
2. بازکردن DevTools > Console و بررسی خطای قرمز.
3. بارگذاری مجدد و بررسی حالت آفلاین.
4. آزمایش زبان، تاریخ، فاکتور و نمودار.
5. گرفتن پشتیبان JSON پیش از هرگونه ریست.

محدودیت: این بسته از نظر ساختاری بررسی شده است؛ آزمون دستی در مرورگر روی دستگاه نهایی کاربر همچنان لازم است.
